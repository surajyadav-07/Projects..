# 🎮 Number Guessing Game

A simple Python game where the computer generates a random number and the player tries to guess it with hints.

## 🔗 Features

- Generate Random Number
- Unlimited Attempts
- Too High / Too Low Hints
- Attempt Counter
- User Friendly Interface
- Replay Option (Optional)

## 📚 Concepts Used

- Variables
- Loops
- Conditional Statements
- Random Module
- User Input
- Functions
